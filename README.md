# Ксенорой

Мобильный top-down шутер в духе Alien Shooter. Пробивайся через лабиринт отсеков станции, отбивай волны тварей, выжигай гнёзда и ищи выход в следующий сектор.

Вся игра — один файл `index.html` (HTML5 Canvas, без движков и зависимостей). Открывается в любом браузере, на телефоне и на ПК.

## Как играть

- **Телефон** (лучше горизонтально): левый палец — ходьба, правый палец — прицел и огонь.
- **ПК:** WASD — ходьба, мышь — прицел, ЛКМ — огонь, 1–5 — смена оружия, P — пауза.
- **Цель сектора:** уничтожить все гнёзда, после этого открывается выход (зелёный маяк на мини-карте).

## Что есть

- Процедурный лабиринт, растёт с каждым сектором; фонарик и тьма, кровь остаётся на полу.
- Волны каждые 20–30 секунд, гнёзда постоянно плодят тварей.
- Враги: ползун, бегун, плевальщик (стреляет кислотой), здоровяк (с 3-го сектора).
- Оружие: пистолет, автомат, дробовик, плазмаган, ракетомёт — по 5 уровней урона и скорострельности.
- Костюм: здоровье, броня, скорость.
- При смерти сохраняется половина добычи сектора. Прогресс хранится в браузере (localStorage).

## Запуск

Открыть `index.html` в браузере. На телефоне при старте игра уходит в полный экран и горизонталь.

**APK:** собирается автоматически в GitHub Actions при каждой загрузке (`.github/workflows/android.yml`, Capacitor). Готовый `xenoroi.apk` — в разделе Releases. Подписан постоянным тестовым ключом `tools/android/xenoroi-test.keystore`, поэтому новые версии ставятся поверх старых с сохранением прогресса. Для RuStore понадобится отдельный боевой ключ, его в репозиторий не кладём.

Чтобы играть по ссылке в браузере, включи GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
